## About

This repository documents my journey from Digital Design fundamentals to RTL Design and Computer Architecture.

The goal is to build a strong foundation for:

- Digital Logic Design
- RTL Design
- FPGA Development
- ASIC Design
- Verification Engineering
- RISC-V Processor Design
